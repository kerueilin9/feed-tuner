# 一行寫一句偏好，例如：
#   我想看遊戲開發
#   不要爭議文章
# 以「不要／不想看／少看／避免」開頭的是不想看的，其他都當作想看的。
# 同一行可用逗號分開，例如：不要業配，抽獎文
# 句尾可加關鍵字，貼文出現任一個就直接算符合：我想看遊戲開發（關鍵字：Godot、Unity）
# 主題寫短一點比較準；加長描述反而會變差。
